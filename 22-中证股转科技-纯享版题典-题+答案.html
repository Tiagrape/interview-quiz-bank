中证股转科技 · 信息技术岗笔试 — 纯享版题典（题 + 答案）

依据中证股转及姊妹单位（中证登等）公开笔经题型规律整理的高频模拟/预测题，非官方真题，附答案供冲刺背诵。题型为金融科技 IT 岗标准三段式：行测 → 计算机专业 → 手写编程。

一、综合能力 / 行测

1. 言语理解与表达

1. 依次填入横线处最恰当的一项是：儒家强调“________”，主张将心比心；道家追求“________”，倡导顺应自然、不妄为。 A. 推己及人 / 无为而治　B. 见贤思齐 / 顺其自然　C. 克己复礼 / 清净无为　D. 三省吾身 / 道法自然 答案：A

2. 下列句子没有语病的一项是： A. 通过本次培训，使我的业务能力有了很大提升。 B. 能否保持清正廉洁，是干部合格的重要标准。 C. 我国高铁运营里程稳居世界第一，已超过 4 万公里。 D. 为了防止不发生类似事故，公司完善了制度。 答案：C（A 缺主语；B 两面对一面；D 否定失当）

3. 对下面这段文字概括最准确的是：“金融科技的本质是金融，技术是手段。脱离风控的技术创新如同无根之木。任何金融活动都必须纳入监管框架。” A. 金融科技将取代传统金融　B. 技术驱动下监管需跟上创新 C. 风控是底线，技术须服从监管与风控　D. 监管会扼制创新 答案：C

4. 语句排序：① 它不仅改变了支付方式，也重塑了商业生态 ② 移动支付在中国的发展世界领先 ③ 从二维码到刷脸，技术迭代迅速 ④ 这正是技术创新与市场需求共振的结果 A. ②③④①　B. ②③①④　C. ①③②④　D. ②①③④ 答案：B

5. 面对复杂市场环境，企业不能 ________，必须未雨绸缪。 A. 临渴掘井　B. 居安思危　C. 防患未然　D. 高枕无忧 答案：A（与“未雨绸缪”正反相对）

6. 下列句子中成语使用不正确的一项是： A. 这篇论文见解独到，真可谓不刊之论。 B. 他做的报告汗牛充栋，听众却昏昏欲睡。 C. 面对质疑，他侃侃而谈，从容不迫。 D. 这部作品文不加点，一气呵成。 答案：B（汗牛充栋形容书籍极多，不能形容报告）

7. 对下面这段文字概括最准确的是：“数字经济不是虚拟经济，而是实体经济的数字化升级。它既包含数字产业化，也包含产业数字化。推动数字经济与实体经济深度融合，是高质量发展的必由之路。” A. 数字经济是虚拟经济　B. 数字经济将取代实体经济 C. 数字经济与实体经济融合是高质量发展必由之路　D. 产业数字化不重要 答案：C

8. 语句排序：① 数据已成为关键生产要素 ② 数字技术的发展使其价值凸显 ③ 各国纷纷布局数字经济 ④ 谁掌握数据谁就掌握未来 A. ①②③④　B. ②①③④　C. ①③②④　D. ②①④③ 答案：A

9. 在推进改革的过程中，我们要 ________，不能眉毛胡子一把抓。 A. 统筹兼顾　B. 各行其是　C. 独善其身　D. 墨守成规 答案：A

10. 下列句子没有语病的一项是： A. 由于天气原因，使航班延误。 B. 他的事迹对于我们是陌生的。 C. 这款产品深受用户所欢迎。 D. 经过努力，他终于取得了成功。 答案：D（A 缺主语；B 主客颠倒；C “深受……所”杂糅）

2. 数量关系

11. 甲单独做需 10 天，乙单独做需 15 天，两人合作需几天？ A. 5　B. 6　C. 7　D. 8 答案：B（1÷(1/10+1/15)=6）

12. A、B 相距 120km，甲以 40km/h 先出发 1 小时，乙以 60km/h 从同地追，几小时追上？ A. 2　B. 3　C. 4　D. 5 答案：A（40÷(60−40)=2）

13. 从 5 男 3 女中选 3 人，至少 1 女，有几种？ 答案：46（C(8,3)−C(5,3)=56−10）

14. 掷两枚均匀骰子，点数和 > 9 的概率？ 答案：1/6（(4,6)(5,5)(6,4)(5,6)(6,5)(6,6) 共 6 种 / 36）

15. 数字推理：2, 6, 12, 20, 30, ? A. 36　B. 40　C. 42　D. 44 答案：C（n(n+1)）

16. 一件商品成本 100 元，按标价 8 折出售仍获利 20%，标价是多少元？ 答案：150（0.8x=120 → x=150）

17. 100g 浓度为 10% 的盐水加入 10g 盐，新浓度约？ 答案：18.2%（(10+10)/(100+10)≈18.2%）

18. 父子年龄和 60 岁，5 年前父是子的 4 倍，现在父子各几岁？ 答案：子 15 岁，父 45 岁（设子 x：55−x=4(x−5) → x=15）

19. 一条路长 100 米，每隔 10 米种一棵（两端都种），共几棵？ 答案：11（100/10+1）

20. 数字推理：1, 1, 2, 3, 5, 8, ? 答案：13（斐波那契数列）

3. 判断推理

21. 有人认为“多刷题就能通过笔试”，最能削弱的是： A. 有人刷很多题仍没通过　B. 笔试还考查心态与知识迁移，刷题无法覆盖 C. 刷题能熟悉题型　D. 历年题重复率高 答案：B

22. 图形推理（规律描述）：每幅图黑点数量依次为 1、2、3、4，则第 5 幅有几个？ 答案：5

23. 类比：程序员：代码 = 作家：？ A. 小说　B. 笔　C. 读者　D. 出版社 答案：A（产出物）

24. 下列属于“沉没成本”的是： A. 已花 3000 元买的不可退培训，决策是否继续时这 3000 元 B. 未来要交的房租　C. 预计的奖金　D. 下月水电费 答案：A（已发生且不可收回）

25. 已知“下雨 → 地湿”，现知“地湿”，能否推出“下雨”？ A. 能　B. 不能　C. 有时能　D. 视情况 答案：B（肯定后件不能肯定前件）

26. 下列能加强“读书能提升认知”的是： A. 研究显示阅读量与认知测试得分正相关　B. 有人不读书也聪明 C. 读书费时间　D. 书很贵 答案：A

27. 类比：医生：医院 = 教师：？ A. 学校　B. 学生　C. 课本　D. 教室 答案：A（职业与场所）

28. 图形推理（规律描述）：图形每次顺时针旋转 90°，第 3 幅为横向，则第 4 幅为？ 答案：纵向（再转 90°）

29. 所有 A 是 B，所有 B 是 C，则可推出？ 答案：所有 A 是 C（三段论传递）

30. “所有同学都及格了”的矛盾命题是？ 答案：有的同学没及格

4. 资料分析

材料 1：某科技公司 2023 年营收（亿元）：Q1=120，Q2=150，Q3=180，Q4=200；2022 全年 540。

31. 2023 全年营收？ 答案：650 亿 32. Q4 环比增速？ 答案：(200−180)/180≈11.1% 33. 上半年占全年比重？ 答案：(120+150)/650≈41.5% 34. 2023 同比增长率？ 答案：(650−540)/540≈20.4% 35. 哪一季环比增速最高？ 答案：Q2（(150−120)/120=25%）

材料 2：某银行 2023 各季度不良贷款率：Q1=1.5%，Q2=1.4%，Q3=1.3%，Q4=1.2%；贷款总额 Q1=1000 亿，每季递增 100 亿。

36. Q4 贷款总额？ 答案：1300 亿（1000+300） 37. 全年平均不良率（算术平均）？ 答案：(1.5+1.4+1.3+1.2)/4=1.35% 38. 不良率整体变化趋势？ 答案：逐季下降 39. Q3 不良贷款余额？ 答案：1100×1.3%=14.3 亿 40. 全年不良贷款总额？ 答案：1000×1.5%+1100×1.4%+1200×1.3%+1300×1.2%=61.6 亿

二、计算机专业

5. 数据结构与算法（41–60）

41. 平均时间复杂度最优的排序是？ A. 冒泡 O(n²)　B. 快速 O(nlogn)　C. 插入 O(n²)　D. 选择 O(n²) 答案：B

42.（不定项）线性时间复杂度的排序有？ A. 计数　B. 基数　C. 桶　D. 归并 答案：A、B、C

43. 二叉树第 k 层最多节点数？ 答案：2^(k−1) 44. 完全二叉树 200 个节点，叶子节点数？ 答案：100 45. 对二叉搜索树（BST）做中序遍历得到？ 答案：升序（有序）序列 46.（不定项）哈希冲突解决方法有？ A. 开放定址法　B. 链地址法　C. 再哈希法　D. 二分查找 答案：A、B、C

47.（不定项）栈的应用有？ A. 递归　B. 表达式求值　C. 括号匹配　D. 广度优先搜索 答案：A、B、C（D 用队列）

48. 哪种数据结构最适合 BFS？ 答案：队列 49. Dijkstra 最短路径算法基于什么策略？对权值有何要求？ 答案：贪心；边权必须非负 50. 平衡二叉树（AVL）任意节点左右子树高度差不超过？ 答案：1

51. 堆通常是一种什么结构？大顶堆满足什么？ 答案：完全二叉树；父节点 ≥ 子节点 52. 红黑树的关键性质（任写两条）？ 答案：根和叶为黑；红节点的子必为黑；任一路径黑节点数相同 53. B+ 树相比 B 树更适合数据库的原因？ 答案：非叶只存索引、叶节点串成有序链表，范围查询与磁盘 IO 友好 54. 快速排序最坏时间复杂度及触发条件？ 答案：O(n²)；已有序且首元素作轴 55. 归并排序的空间复杂度与稳定性？ 答案：O(n)，稳定

56. 判断单链表是否有环通常用？ 答案：快慢指针（Floyd） 57. 栈溢出最常见于？ 答案：递归过深 / 无限递归 58. 哈夫曼树用于？ 答案：数据压缩（带权路径最短） 59. 拓扑排序适用于？ 答案：有向无环图（DAG）的任务调度 60. 图的 DFS 遍历借助？ 答案：栈（递归或显式栈）

6. Java 语言（61–80）

61.（不定项）String a="ab"; String b="ab"; String c=new String("ab"); 哪些为 true？ A. a==b　B. a==c　C. a.equals(c)　D. b==c 答案：A、C（常量池复用；new 在堆，== 比地址为 false）

62. ArrayList 与 LinkedList：随机访问更快的是？频繁中间插入删除更适？ 答案：ArrayList 随机访问快；LinkedList 插入删除频繁时更合适 63. JDK8 中 HashMap 底层结构？ 答案：数组 + 链表 + 红黑树（链表长度 >8 转红黑树） 64. synchronized 与 volatile 的区别？ 答案：volatile 保证可见性、禁止重排，不保证原子性；synchronized 保证原子性+可见性+有序性（互斥） 65. Java 创建线程的方式？ 答案：继承 Thread / 实现 Runnable / 实现 Callable / 使用线程池 66. JVM 判断对象可回收的主要算法？ 答案：可达性分析（GC Roots 不可达即回收） 67. 方法重载（overload）与重写（override）的区别？ 答案：重载同一类、看参数列表；重写子类覆盖父类、返回协变、不能抛更宽异常 68. Error 与 Exception 的区别？ 答案：Error 表示不可恢复的严重问题（如 OOM）；Exception 可被捕获处理 69. 泛型类型擦除发生在？ 答案：编译期 70.（不定项）下列哪些是 Java 基本类型而非包装类？ A. int　B. Integer　C. double　D. Boolean 答案：A、C

71. final 修饰类、方法、变量分别含义？ 答案：类不可继承；方法不可重写；变量引用不可改 72. String、StringBuilder、StringBuffer 区别？ 答案：String 不可变；StringBuilder 可变非线程安全；StringBuffer 可变线程安全 73. == 与 equals 的区别？ 答案：== 比地址（基本类型比值）；equals 默认比地址，String 重写后比值 74. Integer 自动装箱的缓存范围？ 答案：−128 ~ 127 75. 反射的主要用途？ 答案：运行时获取类信息、动态创建对象与调用方法 76. Java 8 主要新特性（任写三项）？ 答案：Lambda 表达式、Stream API、Optional、接口默认方法 77. volatile 能否保证 i++ 的原子性？ 答案：不能（i++ 非原子） 78. 线程池核心参数？ 答案：核心线程数、最大线程数、工作队列、空闲存活时间、拒绝策略 79. 深拷贝与浅拷贝的区别？ 答案：浅拷贝复制引用；深拷贝递归复制对象本身 80. JVM 内存区域主要有哪些？ 答案：堆、方法区（元空间）、虚拟机栈、PC 寄存器、本地方法栈

7. 编译原理（81–90，该单位特色）

81. 编译的主要阶段依次？ 答案：词法分析 → 语法分析 → 语义分析 → 中间代码生成 → 代码优化 → 目标代码生成 82. 词法分析器的输出？ 答案：记号（token）序列 83. 正则式 a(a|b)* 描述的语言？ 答案：以 a 开头、后接任意多个 a 或 b 的字符串集合 84. LL(1) 三个字母的含义？ 答案：自左向右扫描、最左推导、向前看 1 个符号 85. 语法制导翻译（SDT）主要生成？ 答案：中间代码（如三地址码） 86. 什么是 NFA 与 DFA？ 答案：NFA 非确定有限自动机（转移可多值/空）；DFA 确定有限自动机（每状态每符号唯一转移） 87. 语法分析两大类方法？ 答案：自顶向下（如 LL）、自底向上（如 LR） 88. 什么是二义文法？ 答案：同一句子存在两棵或以上不同语法树的文法 89. 常见中间代码形式？ 答案：三地址码、四元式、逆波兰式（后缀表达式） 90. 代码优化的目标？ 答案：减少运行时间或空间占用，且不改变程序语义

8. 计算机网络（91–100）

91. TCP 三次握手过程（标志位）？ 答案：SYN → SYN+ACK → ACK 92. HTTP 状态码 404 含义？ 答案：请求的资源未找到 93. TCP 与 UDP 的核心区别？ 答案：TCP 面向连接、可靠、有流控/拥塞控制；UDP 无连接、不可靠但开销小速度快 94. DNS 的作用？ 答案：域名 → IP 地址解析 95. 计算机网络五层模型？ 答案：应用层 / 传输层 / 网络层 / 数据链路层 / 物理层 96. HTTP 与 HTTPS 的区别？ 答案：HTTPS = HTTP + TLS 加密，端口 443，防窃听篡改 97. TCP 四次挥手过程？ 答案：FIN → ACK → FIN → ACK 98. 子网掩码的作用？ 答案：区分 IP 地址中的网络位与主机位 99. GET 与 POST 的区别？ 答案：GET 参数在 URL、幂等、可缓存；POST 在请求体、非幂等、不可缓存 100. ARP 协议作用？ 答案：IP 地址 → MAC 地址解析

9. 操作系统（101–110）

101. 进程与线程的区别？ 答案：进程是资源分配基本单位；线程是 CPU 调度基本单位；同进程线程共享地址空间 102. 死锁的四个必要条件？ 答案：互斥、占有并等待、不可抢占、循环等待 103. 银行家算法用于？ 答案：死锁避免 104. 分页与分段的主要区别？ 答案：分页物理划分、页大小固定；分段逻辑划分、段大小可变 105. 生产者—消费者问题用何种机制同步？ 答案：信号量（semaphore）/ 互斥量 + 条件变量 106. 虚拟内存的作用？ 答案：扩展进程逻辑地址空间，按需调页，让程序可用超过物理内存的空间 107. 常见页面置换算法？ 答案：FIFO、LRU、OPT（最佳） 108. 进程的基本状态？ 答案：就绪、运行、阻塞 109. 什么是临界区？ 答案：访问共享资源的代码段，执行需互斥 110. 死锁预防与避免的区别？ 答案：预防破坏四条件之一（静态）；避免用银行家算法动态判断（如安全序列）

10. 数据库（111–120）

111. 写出 SQL：查询 score 表中每科平均分大于 80 的科目及平均分。 答案：

SELECT subject, AVG(score) AS avg_score
FROM score
GROUP BY subject
HAVING AVG(score) > 80;

112. 事务的 ACID？ 答案：原子性、一致性、隔离性、持久性 113. 建立索引的代价？ 答案：加速查询，但占存储、降低增删改性能 114. 第三范式（3NF）要求消除？ 答案：传递依赖 115. 什么是“脏读”？ 答案：一个事务读到了另一个事务尚未提交的数据 116. DROP、DELETE、TRUNCATE 的区别？ 答案：DROP 删表结构；DELETE 删行可回滚；TRUNCATE 清空表快且不可回滚 117. 左连接与右连接的区别？ 答案：左连接保留左表全部行；右连接保留右表全部行 118. 什么是视图（View）？ 答案：基于 SQL 查询的虚拟表，不存实际数据 119. 主键与外键的区别？ 答案：主键唯一标识本表一行；外键引用另一表的主键以建立关联 120. 事务的隔离级别（由低到高）？ 答案：读未提交、读已提交、可重复读、串行化

三、编程题（机考手写，非 OJ、无自动补全）

121. 两数之和：给定数组 nums 与目标 target，返回两数之和等于 target 的下标。

public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> m = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        if (m.containsKey(target - nums[i]))
            return new int[]{ m.get(target - nums[i]), i };
        m.put(nums[i], i);
    }
    return new int[]{};
}

122. 反转单链表。

public ListNode reverse(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode nxt = cur.next;
        cur.next = prev;
        prev = cur;
        cur = nxt;
    }
    return prev;
}

123. 最大子数组和（LeetCode 53）。

public int maxSubArray(int[] a) {
    int max = Integer.MIN_VALUE, cur = 0;
    for (int x : a) {
        cur = Math.max(x, cur + x);
        max = Math.max(max, cur);
    }
    return max;
}

124. 买卖股票的最佳时机（LeetCode 121，姊妹单位一面原题）。

public int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE, profit = 0;
    for (int p : prices) {
        minPrice = Math.min(minPrice, p);
        profit = Math.max(profit, p - minPrice);
    }
    return profit;
}

125. 合并区间（LeetCode 56，姊妹单位一面原题）。

public int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (x, y) -> x[0] - y[0]);
    List<int[]> res = new ArrayList<>();
    for (int[] it : intervals) {
        if (res.isEmpty() || res.get(res.size()-1)[1] < it[0])
            res.add(it);
        else
            res.get(res.size()-1)[1] = Math.max(res.get(res.size()-1)[1], it[1]);
    }
    return res.toArray(new int[0][]);
}

126. 接雨水（LeetCode 42，姊妹单位一面原题）。

public int trap(int[] h) {
    int l = 0, r = h.length - 1, lo = 0, hi = 0, ans = 0;
    while (l < r) {
        lo = Math.max(lo, h[l]);
        hi = Math.max(hi, h[r]);
        if (lo < hi) ans += lo - h[l++];
        else         ans += hi - h[r--];
    }
    return ans;
}

127. 有效的括号（LeetCode 20）。

public boolean isValid(String s) {
    Deque<Character> st = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') st.push(c);
        else {
            if (st.isEmpty()) return false;
            char t = st.pop();
            if ((c == ')' && t != '(') || (c == ']' && t != '[') || (c == '}' && t != '{')) return false;
        }
    }
    return st.isEmpty();
}

128. 二分查找（有序数组）。

public int binarySearch(int[] a, int x) {
    int l = 0, r = a.length - 1;
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (a[m] == x) return m;
        else if (a[m] < x) l = m + 1;
        else r = m - 1;
    }
    return -1;
}

129. 二叉树层序遍历（BFS）。

public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new LinkedList<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int n = q.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            TreeNode cur = q.poll();
            level.add(cur.val);
            if (cur.left != null) q.offer(cur.left);
            if (cur.right != null) q.offer(cur.right);
        }
        res.add(level);
    }
    return res;
}

130. 爬楼梯（LeetCode 70，动态规划）。

public int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}
