## 中证股转题典说明
依据中证股转及姊妹单位（中证登等）公开笔经题型规律整理的**高频模拟 / 预测题**，**非官方真题**。
- **行测 40 题**：言语理解 / 数量关系 / 判断推理 / 资料分析
- **计算机专业 80 题**：数据结构 / Java / 编译原理 / 计算机网络 / 操作系统 / 数据库
- **手写编程 10 题**：含 LeetCode 121（买卖股票）、56（合并区间）、42（接雨水）等原题思路

金融科技 IT 岗校招笔试标准三段式：综合能力（行测）→ 计算机专业（单选+不定项）→ 机考手写编程（富文本编辑框，非 OJ、无自动补全）。
